TITLE
Driftor: "Done" is a claim. Prove it. (Kane CLI hackathon demo)

DESCRIPTION
AI coding agents say "done" when the unit tests pass. But unit tests run in a pretend browser, so the bugs your users hit walk straight through. In our bug zoo, unit tests caught 0 of 5 real-browser bugs. Kane CLI, in real Chrome, caught all 5.

Driftor plugs into Claude Code as hooks and makes the agent prove its work in a real browser before it can stop:
- Tests from the task: Kane CLI designs acceptance tests from your request and runs them before any code is written (red), then again after (green).
- A guard that blocks the agent from weakening or deleting tests instead of fixing the app.
- A "what the user saw" card from Kane's evidence: the screenshot, the failed step and why.

Everything in this film is real: the live Claude Code session of 2026-11-24 (both Kane tests failed before the change and passed after), the bug zoo runs of 2026-11-23, the guard replay and Kane CLI's own screenshots and verdicts.
